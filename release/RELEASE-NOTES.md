# Creo CLI 1.1.0-beta.1 — Windows x64 prerelease

Complete isolated unsigned Windows distribution with a rebuilt client and original JAR/DLL,
manifest verification, owned startup helpers and six mechanical-task Skills.
Initialization no longer depends on private sample archives. It creates empty
project directories and retains the exact staging boundary, reinitialization refusal,
continuing history and stop-on-unknown behavior.

Only the client is rebuilt with project-controlled Python 3.15.2 from official
sources, patched XZ 5.8.4, OpenSSL 3.5.9, SQLite 3.53.4 and PyInstaller 6.22.3.
The JAR/DLL remain unchanged. The runtime is not an unmodified PSF binary package.
The initializer, runtime compatibility and packaging are checked offline against the final package.
Those checks do not add native engineering or clean-machine qualification.
The exact three components also completed one owned, visible, empty-session cold
start (27.60 seconds) and one fresh preview/confirmation for normal ProEngineerEnd
exit (held-process exit code 0). Generation, process, recovery and the applicable
isolated unsigned policy were checked. No model was loaded or changed; the prior
14 unknown/running history records were unchanged. See NATIVE-START-EXIT.json for
component-bound evidence digests and the limited scope of this observation.
Bounded native observations remain limited to visible-window Creo 13.4.1.0/JDK 25.0.3,
source RGB, rigid placement and save/empty/reopen/normal-exit paths. Complex assemblies
can take minutes. Material/density edits, instance-only appearance, advanced assembly,
frozen STEP/deletion/symbol paths, other hosts and headless operation remain restricted.

The public snapshot excludes private CAD projects, images, raw receipts, developer
handoffs, Hub configuration and old Git ancestors. The historic command-path index
is a derived summary, not newly executed evidence. Full Functional Contract Coverage
has not been established; the product continues to report beta/partial readiness.
