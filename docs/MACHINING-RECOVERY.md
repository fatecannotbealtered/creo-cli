# 孔与圆角：引用、基准平面及未知结果登记

本说明限定简单线性定位通孔，以及沿模型坐标轴的正交外边恒定半径圆角。
命令树和公共运行时协议不变；高级孔、复杂拓扑与变半径没有因此增加验收。

## 引用先解析到实际对象

`edge:54`、`EDGE:54` 等大小写写法解析到实际读回的同一对象。
基准名称也按实际对象解析；例如 `FrOnT` 和该基准的 `surface:<id>` 别名会采用
读回的基准名称。不存在、歧义或重复指向同一对象的引用仍拒绝，不能猜测替代对象。

预览、原生请求及写后定义比较使用实际对象身份；请求文件的原始内容与物理身份仍绑定。
预览后只改文件中字母的大小写，也属于输入文件变化，需要重新预览。
圆角创建前的边可能在创建后被消耗，定义引用因此与创建前快照比较，当前实体几何另行验证。

## 有限面与无限基准平面

实体平面有实际材料边界。可读取的有限面范围用于孔预检，不能由显示大小代替。
基准平面是无限的定位参考，其显示范围和面积不参与材料边界检查，也不作为几何身份版本。
基准的真实位置、法向、ID 和所属特征仍参与绑定；这些变化会拒绝陈旧确认。
真实实体的外包围范围可排除接触或跨越板边的圆形孔口；它只提供必要的拒绝条件。
即使孔口位于该范围内，也不能据此证明裁剪面、已有缺口或材料完整。

预览分别给出定位中心、轴线、孔径、贯穿范围、切除意图和已完成的预检范围。
基准定位的材料相交关系仍须写后验证，预览不声称已经证明实体切除。
成功必须独立读到当前实体上的实际孔面、正确中心与轴线、半径和贯穿范围，
并核对原生定义和无关尺寸/特征。active 特征、setter 返回值或数量增加均不能单独通过。
完整通孔还要求孔壁总面积为 2πrt、切除体积为 πr²t；上下孔口必须分别构成闭合圆周，
与实际顶／底实体面相邻，不能出现通向侧面的开口。闭合检查核对连接关系和圆周长度，
不能只数边或只比较包围盒。缺少面积、圆周端点或邻接读回时，不能登记 applied。
这些判据限定于坐标轴对齐的简单板件；比较阈值是数值核验阈值，不是制造公差。

## 丢回复后按保留意图检查

先查询原记录，再独立读取当前模型：

```text
operation show --id <原操作ID>
operation query --id <原操作ID> --model <明确零件>
```

`observation.machining_verification` 给出 `accepted`、`can_register`、逐项检查、冻结意图
和当前读回。该查询不修改原生模型，也不登记原操作结果。
比较使用保留计划中的请求和创建前快照，不读取后来改变或删除的请求文件作为新意图。
当前服务实例必须与原操作一致；旧记录缺少足够数据或新实例中找不到模型，都不能推断未应用。

新毫米完整通孔只在新预览中冻结`bounded-total-v2`：根据实际mm³单位读回，
同时使用总体积相对阈值和0.001mm³绝对残差上限，保留去料差值诊断及完整几何判据。
具体比较、有效预算和物理面归属要求见[原生通孔配方](HOLE-ROUND-WORKFLOW.md#原生通孔的数值比较)。
query和resolve复用`baseline.machining_intent`中的原政策，不能按当前默认重新赋值。
新毫米完整通孔还必须保留`retained-solid-boundary-v1`，保护原有实体面、边、单活动体、
包围范围和独立非家族身份。体积或原生孔定义正确不能替代这项保护。
缺少新政策的旧意图保持legacy差值比较；缺少整个旧意图时，有限重建也只能使用legacy。
显式null、未知版本、半缺新政策、必要单位或冻结几何字段缺失均不能当成legacy成功。
缺少实体保护政策的旧记录不会被补成V1；当前检查会明确报告保护不足，不能新登记完整applied。
这不撤销或改写历史回执、既有登记或当时已执行的工程事实。
旧计划即使其体积残差符合新的数值范围，也不因此获得applied；只能按其原判据及当前完整、
稳定的独立事实判断是否支持partial。登记保留原失败回执，不重新创建、重放或自动保存。

确认支持所选结果后，沿用既有登记入口：

```text
operation resolve --id <原操作ID> --outcome applied --evidence <独立检查依据>
```

登记会再次读取实际状态，并保存独立检查证据。孔必须满足被冻结的中心、轴线、直径、
贯通范围和切除意图；圆角必须满足半径、原引用、所选外边上的实际几何位置、
完整轴向范围与曲面面积。部分长度的圆角不能借用正确半径和位置通过。
若使用登记的 dry-run/confirm 形式，这份检查快照也绑定到确认，不能接纳步骤间漂移。

| 独立观察 | 登记边界 |
|---|---|
| 正确新特征、实体几何与冻结意图相符，其他条件通过 | 可以明确登记 applied |
| 完整读回证明存在部分变化，但没有达到原意图 | applied 拒绝；只允许明确登记已证明的 partial |
| 完整、稳定的当前快照与创建前一致 | 可以明确登记当前未应用状态，不改写原调用的不确定性 |
| 轴线、定义、范围或原始意图缺失，实例不同，或两次读回不稳定 | 证据不完整，保留 unknown |

原回执和失败证据保留，登记不重放、不回滚、不自动保存模型。
图纸、STEP 消费及完整图面检查仍是后续工程验收，不能由这份局部恢复证明代替。
