# 安装板材料与尺寸公差操作配方

下文的数值和名称是语法示例，不能替代当前工程需求、独立读回或本次对象 ID。

本配方面向已有 Creo CLI 操作基础的工程代理，限定已有可编辑零件和明确目标尺寸。
参数及 Schema 以 `reference --command` 为准；材料、公差和模型精度属于不同属性。
本轮的材料和偏差为合成验收数据，不代表公司标准、材料牌号或制造签核。

## 先冻结意图与输入

先读取模型单位、实际尺寸名、特征、几何与保存文件。材料赋值限定 mm/tonne 零件。
使用工作区内明确的现代 UTF-8 `.mtl` 文件，名称必须与文件名主干一致。
也可从 `material list` 解析唯一库项，但实际来源文件必须可读，并得到 scope 的观察授权。
绑定包括规范路径、文件身份、内容摘要和密度；预览后内容变化或同内容替换均拒绝。
当前密度解析支持 tonne/mm³、kg/m³、g/cm³，不支持未知编码和未识别密度单位。

验收安装板为 80×50×6 mm、两枚 Φ6 通孔和一个 R1 外边圆角。
合成材料密度为 2700 kg/m³，即 2.7×10⁻⁹ tonne/mm³。
目标孔径的上偏差为 +0.10 mm、下偏差为 −0.05 mm；宽度为 80±0.20 mm。
模型选择 ISO 模式和 medium 类。这是显式测试配置，不能由模型设置推断图纸已声明一般公差。

## 分步预览、确认和独立读回

1. `material assign`：对实际来源文件预览，确认后读回材料名称、原始密度属性及单位、
   模型单位中的密度、体积与质量。独立比较质量＝密度×体积；核对几何和无关尺寸未变。
   加载只临时使用原生材料检索目录，核对有效目录及工作目录恢复，不写持久配置。
   Creo 对未显式设置的目录可能返回默认路径，原始字符串及有效路径分别保留。
2. `model set-tolerance-standard`：选择实际支持的模式及适用类别，独立读取模型属性。
   明确尺寸公差保持；一般模式变化不等于赋予所有尺寸同一制造公差。
   既有数字公差的值先冻结，再解除表引用并再生成，防止一般表覆盖显式偏差。
   ISO fit 转 ANSI 暂不支持。旧文件中其他数字公差仍由表控制时，单尺寸编辑预先拒绝；
   先明确预览当前模式／类别的标准入口，核对保留的所有数字公差及解除引用，再编辑目标。
3. `dimension set-tolerance`：以实际尺寸名选择目标，数字偏差使用尺寸自身单位。
   `--minus` 是下偏差幅值；+0.10/−0.05 对应 plus 0.10、minus 0.05。
   写后核对公差类型、上下偏差和极限值，其他尺寸及原生几何保持。
4. 明确保存、关闭自有模型并重开，再读取以上全部属性和可编辑特征。
   孔径做 6→8→6 mm 往返时，分别核对极限值 8.10/7.95 和 6.10/5.95 mm。

这三条路径沿用公共 scope、预分配操作 ID、预览绑定、五维回执和未知结果阻断。
它们可组合在已有模型、明确目标及路径、最多 32 步的有界 workflow 中。
本轮组合支持数字 plus_minus、symmetric、limits；可配合再生成、保存、已有图纸编辑与 STEP/PDF。
basic、nominal、fit，以及参数／关系／名义尺寸／特征几何编辑混排尚未验证，父预览直接拒绝。
保存是单独操作，赋值成功不能视作已保存。

前序标准步骤可以为后续数字公差计划声明待验证条件，但不代表条件已经满足。
实际执行时，必须读回前序保留的数字值及已解除的表引用，再按普通叶命令完整预检。
材料实际文件的观察授权、内容、物理身份及库解析结果，从整体预览冻结到最后一步。
同内容替换、内容变化、改指另一文件或 scope 变化都不能作为新基线自动确认。
中途失败停止；最后一步后仍核对文件、属性和依赖。已完成子回执保留，父结果按实际报告 partial 或 unknown。
结构示例见 [已有模型的属性任务](../examples/engineering/workflow-existing-properties.json)。
使用前替换模型、实际尺寸名和材料路径；示例中的 d1 不代表任意零件的宽度。

## 关联图纸与独立消费

公差文字可能扩大标注范围。出图前预留尺寸区域；放置和移动时检查可读原生文字框、
视图轮廓和已知冲突。无法读到的引线范围或文字框明确列为未检查。
更新关联图纸、保存重开，核对图纸尺寸的模型归属和公差读回，再导出 STEP/PDF。

STEP 的独立消费者核验 mm、有效实体、孔位/孔径、贯通和体积；通常不携带原生材料及尺寸公差。
质量交叉检查应明确使用 STEP 体积与已独立读回的密度，不能声称 STEP 自身证明了材料。
PDF 必须逐页渲染和全页查看，检查孔径、上下偏差、宽度文字、引线与轮廓。
位置参考尺寸保留 REF。自动文字框检查和目视可读性分开留证。
长度/体积的验收数值比较阈值不是尺寸制造公差，也不是模型精度。

## 失败后保留现场

先查询原操作和当前模型。丢回复或最终回执存储失败保留 unknown，相关写入拒绝，
重复确认不重放。材料和公差记录目前采用显式独立检查后的既有结果登记入口；
应提交材料/公差、几何、保存状态及记录的证据，不把 getter 回显当作自动恢复完成。
孔与圆角采用额外的保留意图及当前实体门禁，见 [MACHINING-RECOVERY.md](MACHINING-RECOVERY.md)。

原生接口依据：[材料属性及模型单位](https://support.ptc.com/help/creo_toolkit/otk_java_pma/r13/usascii/creo_toolkit/user_guide/Accessing_Material_Properties.html)、
[Part.RetrieveMaterial](https://support.ptc.com/help/creo_toolkit/otk_java_pma/r13/usascii/creo_toolkit/api/dita/c-pfcPart-Part.html)。
真实运行范围、构件及未执行项以本轮公开证据摘要为准。
