# Open-source checklist

- [x] Independent-product and third-party notice supplied; MIT source license.
- [x] No proprietary CAD models, SDK binaries, license files or secrets intentionally included.
- [x] Mock fixtures explicitly labeled, native support explicitly unverified.
- [x] Write permissions default to read-only; package publication disabled.
- [x] Runtime commands, limitations, setup and handoff documented.
- [ ] Exact spec files/codegen integrated and full conformance reviewed.
- [ ] Formatter/linter and dependency audit recorded.
- [ ] Owner's authenticated remote creation/push verified.
- [ ] GitHub CI matrix run and reviewed.
- [ ] Native SDK/live acceptance recorded before native stability claims.
- [ ] Binary/npm supply-chain and install verification before package release.

Checked items are source-review assertions, not formal security certification.
