## Known Limitations

- creo-cli 1.0, Creo Parametric 13.4: verified only on Creo Parametric 13.4.1.0 under Windows 11 x64. A locked screen or a minimized Creo window was never qualified.
- creo-cli 1.0: `model render` takes its picture from the model's own window, active or not; a model in session only as part of an assembly or drawing has no window and is refused until it is opened with `doc open`.
- creo-cli 1.0: a running toolkit call cannot be cancelled, and Creo loads the host component only at start, so an upgrade needs a restart of Creo.
- creo-cli 1.0: on an assembly, the `feature`, `dimension`, `geometry` and `distance` commands see only the assembly's own features, dimensions and datums, not those inside its components.
