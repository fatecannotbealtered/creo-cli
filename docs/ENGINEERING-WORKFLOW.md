# 可编辑模型到工程交付

本文是候选公开操作配方。历史案例和固定机器路径保留在开发记录中，不作为新部署的依赖或新的通过证据。
候选保持 beta、全树 FCC partial；每项工程结果须绑定本次 EXE、实际组件和输入。

尺寸驱动的原生变体使用 [家族表配方](FAMILY-TABLES.md)。泛型、实例和磁盘文件分别核对；
保存泛型后重新检查各模型 modified 状态，再关闭重开。家族叶命令不加入创建式或动态 workflow。

## 准备环境与任务

先按 [Windows 部署](WINDOWS-DEPLOYMENT.md) 安装、核对文件和实际加载来源。
沿用已有 CLI 操作库，读取 `doctor`、`context`、`session status` 和目标命令的 `reference`。
按任务授权填写随包 scope 示例；冻结自有模型副本、单位、目标尺寸、非目标不变量及输出目录。
不要复制历史模型名、对象 ID、端口或服务身份。先读取本次 `model show`、`feature list`、
`dimension list` 和实际几何，再选择对象。

## 编辑、组合与保存

每个写入先 `--dry-run`，检查 `preview.can_apply`、scope、输入、依赖和预分配 operation_id，
再用同一参数和一次性令牌确认。保留公共回执五个维度和独立读回。
材料、标准和数字公差按 [属性配方](ENGINEERING-PROPERTIES.md) 组合；
已有明确对象的 workflow 范围见 [公共生命周期](WORKFLOW-RUNTIME.md)，预算见 [执行预算](WORKFLOW-BUDGET.md)。
创建式操作及创建后才能知道的 ID 仍分段使用明确叶命令。

简单轴套可按[回转零件配方](REVOLVED-PART.md)分段构造偏置基准面、交线基准轴和首个 360° 回转实体。
先区分草绘坐标与模型坐标，核对真实约束、轴线和实体边界；不能只靠特征名称或相同体积。
这三条叶路径不扩展 workflow 创建能力，具体变体和实机证据分别查看配方与本轮交接。

矩形壳体使用[抽壳配方](SHELL-WORKFLOW.md)：先证明毛坯是独立实心棱柱，再选取真实顶面，
核对均匀内壁、底厚和完整开口。厚度修改往返时保留原始驱动尺寸及非目标几何。
同一毛坯的另一副本可按[有界拔模配方](DRAFT-WORKFLOW.md)处理一个侧面；
冻结中性面、拉伸方向和有符号角度，核对实际选面归属及全部平面边界。
两种构造分开验收，不据此承诺薄壁壳体叠加拔模、多面或复杂曲面，也不加入创建式 workflow。

保存之前核对独立尺寸、材料密度、单位、特征和再生成状态。保存后检查版本文件与摘要、modified，
关闭且只关闭自己的已保存模型，再从实际新版本重开检查。继续编辑并恢复一个目标尺寸可证明原生可编辑性；
不可仅由导出几何或 setter 回显推断。

## 关联图纸

先冻结单页尺寸、单位、投影、所需视图和表达内容，为尺寸、孔位、引线和备注预留区域。
从 `drawing create`、`drawing view add` 和 `drawing dimension annotate` 的公开说明开始；
用 `model show`／对应资源读取结果，明确选择当前实际模型尺寸与几何引用。
尺寸拥挤时使用 `drawing dimension move`，不需要的模型尺寸用 `drawing dimension hide`。
参考定位保留 REF；材料及公差只表达已授权并独立核对的数值，签名和未知要求留空。

操作前检查已有视图／表格完整范围和可用文字框；不可读的引线范围明确列为目视待查。
公差文字扩张后再次检查。改变模型尺寸、再生成并更新关联图纸，保存重开，确认关联与文字仍正确。
不得只靠尺寸数字库存判定孔位表达完整或无重叠。

## 导出与独立检查

分别预览／确认 `artifact export` 的明确 STEP 和 PDF 输出，已有输出拒绝覆盖。
STEP 用已声明的独立消费者检查单位、实体有效性、边界、孔位、孔径、贯通和体积；
对于抽壳和拔模，还应核对内外表面、开口和倾斜方向；可用独立构造的目标实体做双向差集比较。
材料与公差以原生读回证明。需要质量核对时明确使用独立体积和原生密度。
PDF 用外部工具渲染全部页面并实际查看：文字、偏差、REF、引线、表格、轮廓、裁切和空白页。
自动几何／文字范围检查与目视结论分列，不能互相代替，也不构成制造签核。

## 失败与续接

失败后先查看父子 operation 记录，保留已完成、failed、partial、unknown、skipped 和文件证据。
`operation query` 提供观察；只有证据支持的 `operation resolve` 才登记结果，不改写原回执。
新任务只包含明确剩余动作。重复确认、缺模型或新实例都不能授权重放 unknown。
交付记录输入／构件摘要、命令和预算、核心预期／实际、保存重开、独立消费及逐页目视，历史结果不累计。
